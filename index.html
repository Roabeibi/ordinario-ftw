Sistema de Estacionamiento

Proyecto desarrollado con ASP.NET Core MVC

Introducción

Este proyecto consiste en un sistema web para la administración y control de un estacionamiento. Permite registrar vehículos, gestionar entradas y salidas, controlar espacios disponibles, visualizar estadísticas dinámicas y generar reportes en tiempo real.

Tecnologías utilizadas

  • ASP.NET Core MVC
  • C#
  • MongoDB
  • HTML5
  • CSS3
  • JavaScript
  • GitHub Pages
  • XML
  • Responsive Design

Funcionalidades principales

  • Login con validación XML
  • Dashboard dinámico
  • Registro de vehículos
  • Control de entradas y salidas
  • Asignación automática de lugares
  • Filtros dinámicos con JavaScript
  • Reportes y estadísticas
  • Hora automática en tiempo real
  • Diseño responsivo
  • Base de datos MongoDB
